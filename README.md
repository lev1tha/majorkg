# MAJOR KG — турнирная платформа по CS2

Многостраничная киберспортивная платформа: публичная часть для игроков и
админ-панель для организаторов. Next.js App Router, Tailwind CSS v4,
Framer Motion (только микро-взаимодействия), Lucide-иконки.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 · админка — http://localhost:3000/admin

```bash
npm run build     # прод-сборка
npm run typecheck # проверка типов
```

## Ключевые механики

**Заявка в два клика.** `JoinProvider` — единая точка входа: любая кнопка
«Участвовать» открывает один модал, в котором состав уже предвыбран.
От клика на витрине до поданной заявки — два действия.

**MIX-подбор** (`src/lib/mix.ts`). Пул делится на пять рейтинговых поясов
FACEIT, каждая команда получает по одному игроку из каждого пояса. Рядом с
игроком на 3000 ELO гарантированно окажутся партнеры уровнем ниже, а средний
рейтинг команд сходится. Подбор детерминирован: одинаковый seed — одинаковые
составы.

**Сетка** (`src/components/tournament/bracket*.tsx`). Раунды — колонки с
равными flex-слотами, поэтому центры матчей следующего раунда попадают ровно
в середину пары предыдущего; соединители рисуются псевдоэлементами, без
пересчета координат в JS. Клик по команде подсвечивает ее путь, клик по
матчу открывает составы, статистику и скаут-заметки на игроков.

**Скаут-заметки** (`src/components/scouting/scout-notes.tsx`). Личные
заметки на игрока перед матчем. Хранятся в `localStorage` браузера автора;
чтобы перенести на бэкенд, достаточно заменить `readStore`/`writeStore` на
запросы к API.

## Интеграции

**Вход через Steam** — OpenID 2.0, официальный механизм Valve, API-ключ для
самого входа не нужен. Маршруты: `/api/auth/steam` → `/api/auth/steam/callback`.
Ответ Steam проверяется повторным запросом `check_authentication`, сессия
подписывается HMAC и кладется в httpOnly-cookie.

**FACEIT** — `src/lib/faceit.ts`, официальный Data API v4. **Без
`FACEIT_API_KEY` интерфейс показывает локальный снимок рейтингов**, а не живые
данные; об этом честно сообщает подпись под таблицами. С ключом ELO и уровень
подтягиваются автоматически и кэшируются на час.

Переменные окружения — см. `.env.example`.

## SEO

- Метаданные на каждой странице + `generateMetadata` для турниров и игроков
- JSON-LD: `SportsOrganization`, `WebSite` с `SearchAction`, `SportsEvent`,
  `ItemList`, `BreadcrumbList`, `FAQPage`, `Person`
- `sitemap.xml`, `robots.txt` (админка закрыта от индексации), canonical, hreflang
- Семантическая разметка, `<time dateTime>`, контент вкладок остается в HTML
  (`forceMount`) и индексируется

Техническая часть закрыта полностью. Позиции в выдаче зависят также от домена,
возраста сайта, внешних ссылок и конкуренции — это вне кода.

## Производительность и граничные случаи

- Списки рендерятся порциями (`PAGE_SIZE`), layout-анимации отключаются на
  больших выборках, поиск через `useDeferredValue`
- Никаких растровых изображений в интерфейсе — только вектор и типографика
- `loading.tsx`, `error.tsx`, `not-found.tsx`; пустые состояния у всех списков
- Таймеры привязаны к моменту монтирования — расхождений гидрации нет
- `prefers-reduced-motion` отключает анимации
